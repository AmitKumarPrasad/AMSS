# AMSS Marketplace Listing

## Product title
**AMSS — AI School Management System Backend | Spring Boot | PostgreSQL | JWT | RBAC | RAG | MCP**

## Short description
Production-oriented AI school management backend for building SaaS, ERP and school-information-system products with Spring Boot, PostgreSQL, Redis, JWT/RBAC, tenant isolation, AI/RAG/MCP capabilities and Docker deployment.

## Full description
Build your school-management product on top of an established backend foundation instead of starting every domain workflow from zero.

AMSS provides a broad school-management API foundation covering identity, multi-tenancy, students, guardians, academics, attendance, assessments, fees, communication, documents, notifications, operations/audit and AI-assisted workflows.
